# Landing Page + Chatbot da FURIA Esports
Este projeto é uma landing page interativa da organização de eSports FURIA, que integra um chatbot em Python capaz de responder dúvidas básicas sobre o time de CS:GO. A aplicação foi desenvolvida com fins educacionais e demonstrativos, simulando um portal informativo rápido, funcional e com integração simples entre front-end e lógica de chatbot.

🔗 Acesse online
Deploy feito com Vercel: https://landing-page-furia-chatbot.vercel.app

📌 Funcionalidades
Landing Page (HTML/CSS/JS)
Interface moderna com informações básicas sobre a FURIA Esports

Estilo inspirado em sites reais de eSports

Links para redes sociais e conteúdos relacionados

Chatbot (Python)
Executado em terminal (linha de comando)

Capaz de responder perguntas como:

Qual o elenco atual?

Quais os próximos jogos?

Onde assistir aos jogos?

Último resultado?

Ranking atual

Loja oficial

Coach do time

Conquistas

Mensagens motivacionais

Lógica feita com condicionais (if, elif) e mapeamento de palavras-chave

🧠 Tecnologias utilizadas
HTML5

CSS3

JavaScript (para interatividade simples)

Python 3.x (para o chatbot)

Git e GitHub (controle de versão)

Vercel (deploy da landing page)
